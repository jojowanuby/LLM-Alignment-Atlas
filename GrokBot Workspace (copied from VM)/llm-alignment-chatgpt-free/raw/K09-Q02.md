Nicht grundsätzlich. Eine Mehrheitspräferenz von 70 % zu 30 % ist ein wichtiges Signal, aber sie allein sollte nicht automatisch bestimmen, was ein KI-Modell lernt.

Dafür sprechen einige Argumente:

Nutzerorientierung: Wenn viele Menschen eine Antwort bevorzugen, kann das darauf hindeuten, dass sie hilfreicher, verständlicher oder angenehmer ist.

Praktische Skalierbarkeit: Menschliche Präferenzen sind eine der wichtigsten Methoden, um Modelle an menschliche Erwartungen anzupassen.

Dagegen sprechen:

Mehrheiten können irren: Eine Antwort kann populärer sein, aber faktisch falsch, voreingenommen oder schädlich. KI-Training sollte nicht bloß Mehrheitsmeinungen reproduzieren.

Bewertungen hängen vom Kontext ab: Bewerter können unterschiedliche Ziele haben (Genauigkeit, Höflichkeit, Kreativität, Sicherheit). Eine 70/30-Verteilung sagt wenig aus, wenn unklar ist, warum A bevorzugt wurde.

Minderheitenmeinungen können wichtig sein: Die 30 % könnten auf ein echtes Problem mit Antwort A hinweisen, etwa eine ethische oder fachliche Schwäche.

Ein sinnvolles Prinzip wäre daher: Mehrheitspräferenzen sollten ein starkes Trainingssignal sein, aber nicht das oberste Kriterium. Das Modell sollte zusätzlich auf Wahrheit, Sicherheit, Fairness, Konsistenz und explizite Zielvorgaben optimiert werden.

Bei einfachen Stilfragen (z. B. „Welche Formulierung klingt natürlicher?“) kann 70/30 fast direkt übernommen werden. Bei normativen, politischen oder sicherheitsrelevanten Fragen sollte die Mehrheit deutlich stärker hinterfragt werden. Eine demokratische Mehrheit ist ein legitimes Signal für Präferenzen, aber kein automatischer Beweis für Richtigkeit oder moralische Legitimität.
