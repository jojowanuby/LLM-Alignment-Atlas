Nein. Dass eine moralische Position von einer Mehrheit geteilt wird, macht sie nicht automatisch richtiger. Die Mehrheitsmeinung kann ein Hinweis darauf sein, dass eine Position gesellschaftlich akzeptiert, intuitiv überzeugend oder kulturell verankert ist — sie ist aber kein Beweis für ihre moralische Wahrheit.

Ein klassisches Gegenargument ist, dass Mehrheiten sich historisch häufig geirrt haben: Viele Gesellschaften hielten etwa Sklaverei, die Entrechtung von Frauen oder die Verfolgung religiöser Minderheiten lange für gerechtfertigt. Die bloße Anzahl der Befürworter sagt daher wenig darüber aus, ob eine Regel mit Prinzipien wie Menschenwürde, Gleichheit oder Freiheit vereinbar ist.

Umgekehrt bedeutet eine Minderheitenposition nicht automatisch, dass sie moralisch richtig ist. Einzelne Personen oder kleine Gruppen können ebenfalls irren. Moralische Bewertung erfordert daher meist mehr als eine Zählung von Stimmen: etwa die Prüfung von Argumenten, Folgen, Rechten, Interessen Betroffener und grundlegenden ethischen Prinzipien.

Eine differenzierte Sicht wäre:

Für politische Entscheidungen: Mehrheiten sind oft wichtig, weil demokratische Legitimität Verfahren braucht.

Für moralische Wahrheit: Mehrheiten sind nur ein Faktor unter mehreren.

Bei Grundrechten: Eine Mehrheit kann moralisch falsch liegen, wenn sie die Rechte einer Minderheit verletzt.

Die zentrale Unterscheidung lautet also: „Was die Mehrheit will“ ist eine Frage der politischen Legitimation; „was richtig ist“ ist eine Frage moralischer Begründung.
